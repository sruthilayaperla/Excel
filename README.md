# Excel Data Analysis

A collection of Microsoft Excel case studies and practice material focused on spreadsheet analysis, reporting, charts, and dashboard work.

## Contents
### Case studies/Excel Analysis
Contains `Excel project 2.xlsx`, supporting analysis documentation, and 17 screenshots.

### Case studies/Sales Analysis
Contains `Sales Analysis.xlsx`, supporting documentation, screenshots, and `work.txt` notes.

### Excel Charts.xlsx
An additional Excel workbook at the repository root.

## Skills Represented
Microsoft Excel, data organization, formulas/calculations, filtering, aggregation, analysis, charting, reporting, and business-oriented interpretation.

## How to Explore
Open the relevant case-study README, then open its `.xlsx` workbook in Microsoft Excel or a compatible application. Review supporting documentation and screenshots where useful.

## Notes
Specific formulas, KPIs, and numerical findings are not asserted here unless documented in the repository.
